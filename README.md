# TeddyPups U.A.E. — Technical Hiring Assignment

An exact, high-fidelity replica and clone of [TeddyPups U.A.E.](https://puppy.instabizweb.com/) — Premium teacup & teddy bear puppies in Downtown Dubai.

## Tech Stack
- **Framework:** Next.js 15 (App Router)
- **Frontend:** React, TypeScript, Tailwind CSS
- **Icons & Graphics:** Lucide React & Hand-crafted SVG mascot/illustrations
- **Forms & Validation:** React Hook Form, Zod
- **Animations:** Framer Motion

## Branching Strategy
- `main`: Production-ready branch.
- `develop`: Primary integration and staging branch.
- `feat/*`: Feature branches branched from and merged back into `develop`.
